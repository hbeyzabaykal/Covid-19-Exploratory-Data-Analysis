# Covid-19-Exploratory-Data-Analysis

Exploratory data analysis is performed on a global Covid-19 dataset using T-SQL in SSMS, combining two separate tables CovidDeaths and CovidVaccinations. The analysis covers death rates and infection rates at the country level, continental death breakdowns, global daily case and death trends, and vaccination progress tracked as both a total and a rolling cumulative count relative to population.

# Tools

SQL Server Management Studio (SSMS)
T-SQL
